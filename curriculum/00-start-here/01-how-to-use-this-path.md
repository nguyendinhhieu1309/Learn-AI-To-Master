# How to Use This Learning Path

## Learning objectives

By the end of this lesson, you can choose a starting point, study a lesson actively, and decide when you are ready to continue.

## What AI means in this course

Artificial intelligence (AI) is the broad field of building systems that perform tasks associated with perception, prediction, language, planning, or decision-making. Machine learning (ML) is one approach within AI: instead of writing every rule by hand, we fit a model to examples. Deep learning (DL) is a family of ML methods based on neural networks with many learned operations.

These names describe overlapping fields, not a ladder where every AI system must use a large neural network. A good rule-based system can be the right solution. This course studies how to choose, build, and evaluate methods for a clearly defined task.

## Pick your starting point

- If you have never programmed, start with the Python module and learn math alongside it.
- If you can write basic Python, start with math review and data processing.
- If you already train models, review data validation and evaluation before choosing a specialization.
- If your goal is robotics, learn general ML and vision foundations before the 3D robotics module.

You do not need to complete every optional topic. Follow the [roadmap](../../ROADMAP.md), then choose the branch that fits your goal.

## Use a repeatable study loop

1. Read the objectives and prerequisite list.
2. Work through the explanation with a small example.
3. Type and run the code yourself; change one input and predict what will happen.
4. Complete the exercise without copying a solution.
5. Write a short note: what you learned, what confused you, and what you want to test next.
6. Keep the code and notes under version control so you can revisit decisions.

## Check understanding

Move on when you can explain the main idea without reading the lesson, reproduce the example, and solve a small variation. If you cannot, reduce the problem size or review the prerequisite. Struggling with a topic is information about what to practice next, not a reason to memorize a formula blindly.

## First action

Write down one AI task that interests you. Describe the input, the output you want, and how you would tell whether the result is useful. Keep this note; it will help you choose a meaningful project later.
