# Computer Vision

## Outcomes

- Describe image representation and common image transformations.
- Apply classical vision methods and modern deep-learning tasks.
- Design an evaluation process for classification, detection, or segmentation.

## Prerequisites

Python, data processing, and basic deep learning. Linear algebra and probability are useful.

## Suggested sequence

1. [Images and classical vision](01-images-and-classical-vision.md)
2. [Deep vision tasks](02-deep-vision-tasks.md)
3. [Video, tracking, and deployment](03-video-tracking-and-deployment.md)
4. [Detection, segmentation, and error analysis](04-detection-segmentation-and-error-analysis.md)
5. [Image pipelines and vision training workflow](05-image-pipelines-and-vision-training-workflow.md)
6. [Computer vision worked lab](06-computer-vision-worked-lab.md)

## Practice

- Visualize color channels and compare image resizing strategies.
- Apply a blur and an edge detector; explain which details disappear or become prominent.
- Evaluate a classifier by class and inspect the hardest misclassified examples.
- Test how lighting, crop, and resolution changes affect predictions.
- Use the [vision problem set](PROBLEM_SET_WITH_SOLUTIONS.md) to practice detection, segmentation, thresholds, split design, and image geometry.

## Checkpoint project

Build an image classifier or detector for a clearly scoped task. Document data provenance, annotation rules, split strategy, metrics, error cases, and inference constraints.
