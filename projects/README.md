# Project Portfolio

Projects turn concepts into evidence of understanding. Start small, state the task and metric before training, keep a baseline, and explain limitations.

## Suggested project levels

- **Beginner:** dataset audit and data report; CSV cleaning utility; simple regression/classification study behind a documented interface.
- **Intermediate:** repeatable ETL pipeline; end-to-end image classification or detection; text search; model-serving API with input validation.
- **LLM engineering:** retrieval application with separate retrieval/answer evaluations, source citations, privacy controls, and cost/latency report.
- **Agent engineering:** bounded LangChain or LangGraph workflow with a reusable skill, narrow tools, persistent state where needed, traces, and human approval for side effects.
- **Advanced:** RGB-D/point-cloud/ROS 2 perception; simulated RL agent with multi-seed analysis; monitored and deployed model system.

## Project write-up checklist

- What problem are you solving and who is it for?
- What data did you use, under which license, and what are its limitations?
- What baseline and evaluation split did you choose, and why?
- What did the system get wrong? How does it behave under a changed input or setting?
- How can another person reproduce the result?
- What would you change before using it in a real setting?
