# Translations

The English curriculum is the source edition. Vietnamese lessons mirror the source paths under translations/vi/, with technical terms kept in English where that supports search and standard usage.

## Layout

~~~text
translations/
└── vi/
    └── curriculum/
        └── <same-module-and-lesson-paths-as-English>
~~~

For example, the Vietnamese version of curriculum/04-machine-learning/README.md lives at translations/vi/curriculum/04-machine-learning/README.md.

Keep section order, exercises, examples, code, and math aligned so corrections can be synchronized. Use the Vietnamese explanation at first mention while preserving technical terms, library names, and identifiers that learners need to search.

The Vietnamese landing page is [translations/vi/README.md](vi/README.md). The unrelated ai/ directory at the repository root is not part of this curriculum or translation mirror.
