## Kết quả học tập

- Mô tả image representation và các phép biến đổi ảnh thường gặp.

- Thiết kế evaluation cho classification, detection hoặc segmentation.

Python, xử lý dữ liệu và deep learning cơ bản. Linear algebra và xác suất có ích.

## Thực hành

- Trực quan hóa color channel và so các cách resize ảnh.
- Áp blur và edge detector; giải thích chi tiết nào mất đi/nổi bật hơn.
- Đánh giá classifier theo class và xem ví dụ phân loại sai khó nhất.
- Thử ảnh hưởng của ánh sáng, crop và resolution lên prediction.
- Dùng [bộ bài tập vision](PROBLEM_SET_WITH_SOLUTIONS.md) luyện detection, segmentation, threshold, split và hình học ảnh.

## Dự án checkpoint

Xây image classifier hoặc detector cho tác vụ có phạm vi rõ ràng. Tài liệu hóa data provenance, quy tắc annotation, split, metric, lỗi và ràng buộc inference.
